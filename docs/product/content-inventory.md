# Inventaris Konten

## Tujuan
Dokumen ini berisi daftar semua konten yang dibutuhkan untuk website Fase 1, status ketersediaannya (tersedia/placeholder), dan template pengisian untuk tiap jenis konten.

## Template Pengisian Berita
```markdown
- **Judul:** 
- **Kategori:** (Kegiatan/Pengumuman/Prestasi/Pelatihan/Organisasi/Edukasi/Kepramukaan/Informasi Layanan)
- **Tanggal:** 
- **Penulis:** 
- **Ringkasan:** 
- **Isi:** 
- **Foto:** (sertakan alt text)
- **Tag:** 
```

## Template Pengisian Agenda
```markdown
- **Nama kegiatan:** 
- **Tanggal mulai & selesai:** 
- **Lokasi:** 
- **Penyelenggara:** 
- **Deskripsi:** 
- **Kontak:** 
- **Status:** (Akan Datang/Berlangsung/Selesai)
```

## Template Pengisian Album Galeri
```markdown
- **Judul album:** 
- **Tanggal kegiatan:** 
- **Lokasi:** 
- **Penyelenggara:** 
- **Deskripsi:** 
- **Cover image:** 
- **Daftar foto:** (sertakan alt text & caption untuk masing-masing foto)
- **Kategori:** 
```

## Template Pengisian Prestasi
```markdown
- **Nama prestasi:** 
- **Tingkat:** (Kecamatan/Kabupaten/Provinsi/Nasional/Internasional)
- **Tahun:** 
- **Peserta/tim:** 
- **Deskripsi:** 
- **Foto:** 
```

## Catatan Penting
- Semua placeholder harus realistis dan dalam Bahasa Indonesia.
- Foto publik harus mengikuti aturan privasi (foto anak di bawah umur tidak ditampilkan).
- Terjemahan mesin tidak boleh langsung dipublikasikan ke publik tanpa review dari manusia.
